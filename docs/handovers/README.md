# Project handovers

This directory contains persistent, dated snapshots created when work moves between devices or groups of agent sessions.

A handover records the repository and machine state observed at that time, including unfinished experiments, non-Git artifacts, blockers, and safe resume instructions. It is historical context rather than a permanently current plan: owning experiment documents and later commits take precedence.
