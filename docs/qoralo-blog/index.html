Building a NotebookLM-like podcast on my phone

You've probably heard of NotebookLM. Feed it a few sources and it makes a podcast-style conversation. The output isn't as good as a real podcast, and it gives me some AI slop vibes. But it's still pretty impressive.

So I wondered: how good could this be with all inference running on my phone?

The phone version

The prototype writes a script, then reads it in one voice. Model preparation and compilation happen on a computer; inference runs on my Galaxy S23 Ultra.

The tensor outlived its data

Re-reading the old runner, I found a C++ lifetime bug. Its start-of-sequence buffer is destroyed before Run(), but the ONNX tensor only borrows that buffer. Inference then reads freed memory.

Keeping the buffer alive fixes the AddressSanitizer test. I haven't replayed the historical recording, so this isn't a confirmed diagnosis of that clip.

Check the port's memory ownership, not just its model outputs. Producing a valid audio file doesn't mean the inference was valid.

Sources & technical notes

The lifetime bug is confirmed in the retained C++ source and a host-only AddressSanitizer reproduction using real ORT non-owning tensors. No model was loaded. We have not bound that exact source to the old phone executable or replayed the recording with only the lifetime fix. The old first-logit difference does not establish a runtime-only defect when the input lifetime is invalid.
