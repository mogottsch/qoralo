Android LLM benchmark registry

Generic fixed-prompt inference measurements for local Android language-model routes. The dashboard keeps setup, TTFT, prefill, decode, memory, provenance, and raw-output sanity separate.

Output sanity is not quality. looks_sensible only screens each exact output hash for obvious corruption or gibberish. It does not establish correctness, grounding, transcript usefulness, or acceptance. Accelerator rows prove only their recorded provider/offload boundary; process PSS/VmHWM does not establish total GPU-private or vendor memory.
