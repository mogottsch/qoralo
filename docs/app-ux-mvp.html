Material 3 interaction and shape language. Transcript becomes immutable once audio generation begins.

Material 3, with a strict draft-to-frozen model

Sources and one instruction field create an episode script composed of chapters. If review is enabled, the user reads those chapters and asks an editing agent for changes. Locking the script starts audio creation and permanently ends editing. During playback, the frozen transcript can be opened like synchronized lyrics.

Confirmed behavior

One field means one mental model

Length, focus, questions, omissions, audience, and tone are all natural-language instructions—not separate controls.

Hints teach; they do not configure

The chips insert example language into the same text field. They are writing prompts, not hidden structured settings.

The only additional control is review

No title, narrator, duration selector, tone picker, or advanced settings appear here.

Toggle semantics

On: Create produces a chaptered script and stops for review. Off: the script is generated, automatically locked, and proceeds to audio creation without an editing opportunity.

Confirmed behavior

An episode is a sequence of chapters

Each chapter has a name and transcript. The same structure later powers playback navigation and transcript following.

Review is read-only

There is no edit icon, textarea, drag handle, or regenerate button on a chapter. All changes begin with “Edit with agent.”

Draft status is explicit

The user always knows that changes are still possible now and will end at lock.

Confirmed behavior

Conversation is the only editing interface

The agent owns transcript mutations. Users express intent instead of manipulating script text directly.

Every change is summarized

The response names affected chapters and structural changes. “Review changes” returns to the updated chapter view.

Agent capability language is bounded

The intro says what it can change: rewrite, shorten, remove, split, combine, and rename. It does not present a blank, mysterious chatbot.

Important UX safeguard

The agent should never lock the episode. It may edit the draft, but the user owns the irreversible “Lock script & create audio” action.

Transcript is a playback mode, not an editor

It opens over the player, follows the current spoken passage, and can be dismissed back to artwork.

Chapters remain the navigation model
