To maintain fidelity and avoid misinterpretation, several measurements must remain strictly separate:

*   **Setup Cost:** This must be isolated from prompt processing and token generation. It includes model loading, session creation, and initial cache allocation.

*   **Token Generation (Decode Throughput):** This measures the speed of the output stream. It must be clearly separated from the prefill cost and explicitly state whether the first generated token is included in the measurement.
